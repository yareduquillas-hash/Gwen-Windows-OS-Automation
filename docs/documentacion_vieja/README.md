# Documentacion historica

Estos documentos se conservaron para referencia y trazabilidad de decisiones
anteriores. No describen necesariamente el comportamiento actual del codigo.

La fuente de verdad vigente esta en:

- `docs/README.md`
- `docs/AUDITORIA_TECNICA.md`
- `docs/PLAN_IMPLEMENTACION.md`
- `docs/ARQUITECTURA_ADAPTADORES.md`

## Contenido archivado

- `AUDITORIA_COMPLETA.md`: auditoria de una version anterior, con correcciones
  declaradas que no coinciden completamente con el arbol actual.
- `gfn_evolution/`: historial de las iteraciones OCR, procesos, ventanas y
  debug log de GeForce NOW.
- `gwen_evolution/`: plan anterior de la aplicacion Android.
- `FIX_GFN_*.md`, `GFN_ARCHITECTURE_CONTEXT.md` y `OPENCODE_GFN_PLAN.md`:
  decisiones y planes de una fase anterior de GFN.
- `app desing/`: propuestas visuales anteriores.
- `UPWORK_CASE_STUDY.md`: material de presentacion anterior.
- `GOOGLE_DRIVE_SETUP.txt`: guia de configuracion anterior, conservada fuera
  de `data/` para que el directorio de datos sea solo runtime.
- `LEEME_CAPTURA_BOTON.txt`: instrucciones antiguas del flujo OCR/click de GFN.

No se ha eliminado ningun documento durante esta reorganizacion.
